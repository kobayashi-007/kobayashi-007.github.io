参数 类型 必需/可选 默认值 说明
enable boolean 可选 false 是否开启本地搜索功能
preload boolean 可选 false 是否预加载搜索文件。开启时网页加载后自动加载搜索文件；关闭时点击搜索按钮后才加载
CDN string/array 可选 - 搜索文件的CDN地址。如果配置，将使用CDN链接；不配置则使用本地链接

添加任意文件

  • 例如当我们想在网站根目录添加ads.txt文件，来通过站长验证时，我们只需要在/source文件夹下放置该文件即可。
