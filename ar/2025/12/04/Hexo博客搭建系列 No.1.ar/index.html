Hexo博客搭建系列 No.1 بناء مدونة Hexo

Kobayashi٢٠٢٥-١٢-٠٤٢٠٢٦-٠٤-٢٩

This article introduces in detail how to use the Hexo framework to build a personal blog and deploy it on GitHub Pages and Cloudflare Pages. The main content includes:

  1. Environmental preparation: Install Node.js and Git
  2. Configure Git and GitHub: Set SSH keys, create GitHub repository
  3. Initialize Hexo project: Install Hexo, create new blog
  4. Deploy to GitHub Pages: Configure deployment settings, push static files
  5. Deploy to Cloudflare Pages: Connect GitHub repository, automatic deployment
  6. Basic usage method: Create new articles, local preview, publish updates
  7. Hexo博客搭建与主题美化教程导航 - click to jump directly
    This tutorial is suitable for those who want to quickly build a personal blog but don’t want to spend too much cost. By using the free services of Hexo, GitHub and Cloudflare, you can easily create an efficient and simple blog website.

1.التحضير المسبق

  1. المجال（غير ضروري، يمكنك أيضًا استخدام مجال مجاني، أو المجال الموزع من GitHub.io أو Pages.dev）
  2. GitHub（ضروري، تحتاج إلى تسجيل حساب GitHub）
  3. Cloudflare（غير ضروري، تحتاج إلى تسجيل حساب Cloudflare، بحيث يمكنك نشر المدونة في CDN من CF للتعجيل، ولكن يمكنك أيضًا استخدام المجال الموزع من GitHub.io مباشرة）

2.دعم البرمجيات

  1. Node（ضروري）
  2. Git（ضروري）
  3. VSCode（غير ضروري، هذا محرر أكواد خفيف، يمكن أن يساعدك على تطوير عادة برمجة جيدة）

2.1.تثبيت Node

  1. افتح الموقع الرسمي لـ Node، قم بتنزيل برنامج تثبيت Node المناسب لنظامك، وإلا ستحدث مشاكل في التثبيت. عنوان التنزيل: https://nodejs.org/en
  2. التثبيت بعد التنزيل، يمكنك استخدام الدليل الافتراضي للتثبيت C:/Program Files/nodejs/
  3. بعد اكتمال التثبيت، تحقق مما إذا كان التثبيت ناجحًا. اضغط على مفتاح win + R على لوحة المفاتيح، أدخل CMD، ثم اضغط Enter، افتح نافذة CMD، نفذ أمر node -v، إذا رأيت معلومات الإصدار، فذلك يعني نجاح التثبيت.
  4. تعديل مصدر npm. يقوم npm بتنزيل الوحدات المختلفة، افتراضيًا من الخادم الخارجي، والسرعة بطيئة، يُوصى بتكوين مصدر مرآة هوواوي. افتح نافذة CMD، نفذ الأمر التالي:

2.2.تثبيت Git

  1. ادخل إلى الموقع الرسمي لتنزيل Git المناسب لنظامك الحالي: https://git-scm.com/downloads

  2. التثبيت بعد التنزيل، تثبيت Git بسيط، يُوصى باستخدام الدليل الافتراضي C:/Program Files/Git

  3. انقر على بدء في الزاوية اليسرى السفلية من الكمبيوتر، سترى Git CMD و Git Bash و Git GUI.

    • Git CMD هو أسلوب تعليمات سطر أوامر Windows
    • Git Bash هو أسلوب تعليمات نظام Linux (موصى به)
    • Git GUI هو واجهة رسومية (لا يُوصى به للمبتدئين)

3.تكوين مفتاح Git والاتصال بـ Github

أوامر Git الشائعة

3.1.تكوين اسم المستخدم والبريد الإلكتروني

  • تنبيه: املأ اسم مستخدم GitHub الخاص بك، بدون علامات اقتباس
  • تنبيه: املأ بريدك الإلكتروني الخاص بك، بدون علامات اقتباس
    تحقق من نجاح التكوين من خلال git config -l.

3.2.تكوين المفتاح العام للاتصال بـ Github

  1. نفذ الأمر التالي لتوليد المفتاح العام SSH، этот المفتاح العام يستخدم لربط جهازك بـ Github
  • تنبيه: املأ بريدك الإلكتروني الخاص بك، بدون علامات اقتباس
    عندما يُطلب Enter file in which to save the key، اضغط Enter مباشرة، لا يُوصى بتعيين مفتاح للمبتدئين

    بعد ذلك، افتح مجلد .ssh في مجلد المستخدم على القرص C، سترى الملفات التالية
  • id_rsa المفتاح الخاص
  • id_rsa.pub المفتاح العام

    افتح ملف المفتاح العام id_rsa.pub أعلاه بالمفكرة، انسخ المحتوى، ثم ابدأ في تكوين مفتاح SSH في github.
  1. تكوين SSH KEY على GitHub
    ادخل إلى github، انقر على الصورة الرمزية في الزاوية اليمنى العليا، اختر settings، بعد الدخول إلى صفحة الإعدادات، اختر SSH and GPG keys، الاسم اختياري، الصق المفتاح العام في حقل Key.


  2. اختبار الاتصال، أدخل الأمر التالي
  • في第一次连接时，系统会提示 Are you sure you want to continue connecting (yes/no/[fingerprint])?，输入 yes 即可
  • عند ظهور معلومات الاتصال بالحساب، فذلك يعني نجاح المهمة، حتى الآن تم إكمال تحضير البيئة.

3.3.إنشاء مستودع GitHub.io

  1. انقر على زر + في الزاوية اليمنى العليا، اختر New repository، أنشئ مستودع <اسم المستخدم>.github.io.
  2. يجب أن يكون تنسيق اسم المستودع: <اسم المستخدم>.github.io (ملاحظة: البادئة يجب أن تكون اسم المستخدم، هذا مطلوب لمعاينة المدونة لاحقًا، يمكنك تعديل اسم المستودع لاحقًا)
  3. يجب اختيار Public لتيسير الفحص الأولي للمشاكل عند النشر، انقر على Creat repository للإنشاء

4.تهيئة مدونة Hexo

  1. أنشئ مجلدًا لحفظ كود المصدر للمدونة ( المسار الذي اخترته هنا هو D:/Hexo-Blog)، انقر بزر الماوس الأيمن في المجلد، اختر Open Git Bash here
  2. أدخل الأمر التالي في Git BASH لتثبيت Hexo

  1. بعد التثبيت، أدخل hexo -v للتحقق من نجاح التثبيت.
  2. تهيئة مشروع Hexo وتثبيت التبعيات ذات الصلة.

  1. بعد تهيئة المشروع، الهيكل التالي في blog-demo:
  • node_modules: حزم التبعية
  • scaffolds: قوالب لإنشاء المقالات
  • source:用来存放你的文章
  • themes: الموضوعات
  • .npmignore: الملفات التي سيتم تجاهلها عند النشر (يمكن تجاهلها)
  • _config.landscape.yml: ملف تكوين الموضوع
  • config.yml: ملف تكوين المدونة
  • package.json: اسم المشروع والوصف والإصدار ومعلومات التشغيل والتطوير وما إلى ذلك
  1. أدخل hexo cl && hexo s لبدء المشروع
  2. افتح المتصفح، أدخل العنوان: http://localhost:4000/ ، إذا رأيت التأثير التالي، فذلك يعني أن مدونتك قد تم بناؤها بنجاح.
