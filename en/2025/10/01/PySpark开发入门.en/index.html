Introduction to PySpark

Spark is developed in Scala, and PySpark is just a high-level API for Python to operate Spark. The underlying layer still uses JDK to run Scala code logic.

Environment Preparation

Using python3.10

Install JDK

Since Spark is developed in Scala, it requires a JDK environment to run.

  1. Download JDK

    1. Visit https://adoptium.net/zh-CN/temurin/releases?version=11&os=any&arch=any
    2. Select the JDK version that matches your environment and download it.

  2. I downloaded: OpenJDK11U-jdk_x64_windows_hotspot_11.0.28_6.msi

  3. On Windows, simply double-click to run the installer.

    • Note: In the custom installation step, select: Set or reset JAVA_HOME variable.
    • If you forgot to select it, you need to manually add the %JAVA_HOME%\bin variable and write it to the PATH path.

  4. After installation, open the command line window to test:

    You can correctly see the JDK version we installed.

    • If the installation is successful but you cannot see the JDK version information, it means the JAVA_HOME environment variable is missing, and you need to add %JAVA_HOME%\bin to the PATH variable.

Install Hadoop

When Spark starts, it calls winutils.exe (a local tool provided by Hadoop for Windows) to handle basic operations such as file permissions and temporary directory creation, even in Local mode (single-machine non-distributed).

  1. Visit the path to download Hadoop: https://hadoop.apache.org/releases.html

  2. I downloaded: https://dlcdn.apache.org/hadoop/common/hadoop-3.3.6/hadoop-3.3.6.tar.gz

  3. Extract and move to the local installation directory

  4. Configure environment variables: HADOOP_HOME, and add %HADOOP_HOME%\bin and %HADOOP_HOME%\sbin to the PATH variable.

  5. Download winutils.exe that matches the Hadoop version (from winutils repository), and place it in the HADOOP_HOME\bin directory (e.g., D:\develop\hadoop\hadoop-3.3.6\bin)

  6. Verify

Install Spark

  1. Visit the path to download Spark: https://spark.apache.org/downloads.html

  2. I downloaded: https://dlcdn.apache.org/spark/spark-3.5.6/spark-3.5.6-bin-hadoop3.tgz

  3. Extract and move to the local installation directory

  4. Configure environment variables: SPARK_HOME, and add %SPARK_HOME%\bin and %SPARK_HOME%\sbin to the PATH variable.

  5. Verify

  • .count():
